# MUUVA self-hosted fonts

Downloaded 2026-10-25 from the official Google Fonts CSS API and font CDN. Unmodified variable WOFF2 Latin and Latin Extended subsets support the four site languages. Manrope is declared at 400-600; Newsreader at 400-500 with its optical-size axis retained (6-72), using the browser's default optical sizing. No italic styling is currently used in the application; no italic face was previously requested. Add an appropriately licensed italic face if editorial italic is introduced later.

Both families are distributed under SIL OFL 1.1; full original license/copyright notices are included beside the files. Sources: https://github.com/google/fonts/tree/main/ofl/manrope and https://github.com/google/fonts/tree/main/ofl/newsreader. These are development provenance links, not runtime requests.
